This repo mostly contains programmable devices like FPGA related HDL codes using legacy micros. It also contains the BASIC-52 source code and assembly tools.
Another major thing in this repo is FM Tuners using simple control using Micro or Arduino. We can see RDA5807 family along with TEA5767, Si4703 and AR1010 Tuners.
